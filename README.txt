DASHBOARD SIX SIGMA PRODUKSI ROKOK SKT

Isi folder:
- app.py: kode utama dashboard Streamlit
- requirements.txt: daftar library yang dibutuhkan
- data/KLIK-KLIKAN FIXXXX(1).xlsx: workbook sumber data

Untuk GitHub dan Streamlit Community Cloud:
1. Upload app.py, requirements.txt, dan folder data beserta file Excel ke repository GitHub.
2. Di Streamlit Community Cloud, pilih repository tersebut.
3. Main file path: app.py
4. Deploy aplikasi.

Catatan: file Excel harus ikut berada di folder data dengan nama yang sama, atau pengguna dapat mengunggah workbook melalui sidebar aplikasi.
